# 需求基线 v1.1（工程初始化摘要）

## 来源与范围

本摘要基于项目根目录的《大作业一第一阶段.docx》（老师原始作业说明）、此前需求澄清和 v1.1 评审决策。它记录工程初始化时已确认的功能边界，不替代后续逐条需求规格。

## 老师原始要求

- 用户注册、登录；用户只能查看自己创建的问卷及其统计结果。
- 创建问卷时设置标题、说明和匿名填写选项；可发布、设置截止时间、关闭，并提供可分享链接。
- 填写者须先登录。
- 题型至少包括单选、多选、文本填空和数字填空；题目可设置必答。多选题支持限制最少/最多/固定选择数；文本题支持最少/最多字符数；数字题支持最小值、最大值和整数约束。
- 问卷可配置按单选、多选或数字答案触发的题目跳转；跳转规则不写死在程序中。
- 填写时校验输入、保存答卷并支持多人同时填写；可按问卷设置是否允许重复填写。
- 创建者可以查看问卷和题目的统计：单选各选项人数及回答数、多选各选项被选择次数、文本答案列表、数字平均值；可查看整份问卷或单题统计。
- 项目必须使用 MongoDB 存储数据，不使用关系数据库或现成问卷系统框架；第二阶段应在第一阶段成果上迭代。
- 课程要求包含自动或手工测试，并在项目报告中说明设计、测试与真实 AI 使用过程。

## 后续已确认的设计决策

- 所有填写者必须登录。匿名是对创建者隐藏填写者身份，系统内部仍关联账号。
- 每份成功提交的答卷都保留；不因答案内容相同而自动去重。是否允许同一账号重复提交由问卷设置控制。
- 同一账号对同一问卷最多有一份 draft；draft 可恢复继续填写。提交后答卷不可修改。
- 非必答题可主动跳过；被跳转路径略过的题目不要求回答。
- 多选题允许创建者设置最少和最多选择数。
- 跳转按优先级顺序匹配，首条命中规则生效；无命中时进入下一题。第一阶段只允许向后跳转。多选条件支持 ANY/ALL，数字条件支持常见比较运算符。
- 每答完一道题保存进度。只有 submitted 答卷计入统计；题目回答数按实际回答该题的已提交答卷数计算，问卷提交次数单独统计。
- 问卷采用草稿状态；发布后不能修改题目。
